# Gaussian-beam laser-welding physics model and adaptive search

鉄鋼板のビードオンプレート・連続発振ファイバーレーザー溶接を対象とした、物理則ベースの合成データ生成モデルと、少数実験で条件範囲を絞り込む適応探索プログラムです。

入力範囲はレーザーパワー `100–6000 W`、1/e²スポット直径 `50–300 µm`、走査速度 `10–1000 mm/s`。出力は最大溶け込み深さ `[mm]`と、スパッタ量の序数レベル `0–9`です。

> **重要**  
> 本モデルは物理的傾向を持つ合成データ生成器です。実機、材料ロット、焦点位置、シールドガス、表面状態、板厚、ビーム品質などに対して校正されていません。設備条件の決定や安全判断へそのまま使用せず、実験データで係数と閾値を同定してください。

## 実行方法

### 1. 任意間隔の全条件グリッド

```bash
python main.py grid \
  --power-step 500 \
  --spot-step 50 \
  --speed-step 100
```

生成物：

- `output/grid/laser_welding_grid.csv`
- `output/grid/laser_welding_3d_preview.png`

PNGは横並びの2つの3D散布図です。3軸にパワー、スポット直径、走査速度を割り当て、左を溶け込み深さ、右をスパッタレベルの`jet`カラーマップで示します。

### 2. 少数実験による粗密探索

例：「溶け込み深さ2.5 mm以上、スパッタレベル5未満」

```bash
python main.py search \
  --depth-min 2.5 \
  --spatter-max 5 \
  --coarse-points 3 \
  --prediction-points 21 \
  --max-steps 8
```

`--spatter-max`は排他的上限です。`5`ならレベル`0–4`が合格です。

主な生成物：

- `output/search/laser_welding_adaptive_search.gif`
- `output/search/adaptive_search_experiments.csv`
- `output/search/adaptive_search_summary.json`
- 各ステップ・各アクションのPNG

GIF内の遷移は次の4動作を繰り返します。

1. 現在範囲を黒線の粗いグリッドへ分割
2. グリッド交点を実験し、実測制約余裕度を`jet`で表示
3. GP回帰で条件を満たす確率が高い領域を半透明ピンクで表示
4. 有望領域を囲む直方体へ切り直し、その範囲を次ステップの黒グリッドに変更

青い実験点は制約未達、緑付近は境界、黄～赤は余裕を持って達成した点です。ピンクは実測値ではなく、GPが推定した同時成立確率領域です。

## 物理モデルの考え方

### 前提

- 連続発振（CW）の軸対称ガウシアンビーム
- `spot_diameter_um`は加工面上の1/e²強度直径 \(d=2w\)
- 軟鋼相当の厚板に対するビードオンプレート
- 焦点位置、入射角、シールドガス、表面状態、ビームモード品質は固定
- 溶融のみ、熱伝導モード、遷移モード、キーホールモードを滑らかに接続

入力3変数を単純に独立関数の積へ分解すると、実際に重要な \(P/d^2\)、\(P/v\)、\(P/(dv)\) の連成を失います。そのため本実装では、最初に物理的な無次元量・複合量へ変換し、その後に各現象項を合成しています。

### 1. ガウシアンビームのピーク強度

半径方向の強度を

\[
I(r)=I_0\exp\left(-\frac{2r^2}{w^2}\right)
\]

とし、全パワーを積分すると、\(d=2w\)に対して

\[
I_0=\frac{2P}{\pi w^2}
   =\frac{8P}{\pi d^2}
\]

です。したがって、同じパワーでもスポットを小さくするとピーク強度は直径の二乗に反比例して増加します。キーホール形成と反跳圧による飛散は、この強度依存性を強く受けます。

### 2. 溶融に使える体積エンタルピー

室温から融点までの顕熱と融解潜熱を合わせた単位体積当たり必要熱量を

\[
H_m=\rho\left[c_p(T_m-T_0)+L_f\right]
\]

とします。本モデルでは、移動熱源の熱拡散長さと滞留時間のスケーリングをまとめた正規化エンタルピー

\[
\mathcal{H}
=
\frac{\eta P}
{\pi H_m\sqrt{\alpha v r_b^3}}
\]

を使用します。ここで、\(\eta\)は吸収率、\(\alpha\)は熱拡散率、\(v\)は走査速度、\(r_b=d/2\)です。

この式により、

- パワー増加：投入熱量が増え、溶融・キーホール化しやすい
- 速度増加：滞留時間が減り、溶融しにくい
- スポット拡大：エネルギー密度と局所温度上昇が低下する

という基本傾向を同時に表現します。\(\mathcal{H}\)は厳密解ではなく、Rosenthal型移動熱源の次元則を使った現象論的指標です。

### 3. 溶融・キーホール遷移

急激なモード遷移を数値的に不連続にせず、対数空間のシグモイド

\[
S(x;x_c,\Delta)
=
\frac{1}
{1+\exp[-(\ln x-\ln x_c)/\Delta]}
\]

で滑らかに表します。

溶融ゲートは正規化エンタルピー、キーホールゲートは正規化エンタルピーと吸収ピーク強度の積で決定します。

\[
g_m=S(\mathcal{H};\mathcal{H}_m,\Delta_m)
\]

\[
g_k=
S(\mathcal{H};\mathcal{H}_k,\Delta_{H,k})
S(\eta I_0;I_k,\Delta_{I,k})
\]

キーホールが形成されると多重反射により吸収率が上がるため、

\[
\eta=\eta_{\rm cond}
+(\eta_{\rm key}-\eta_{\rm cond})g_k
\]

を固定点反復で解いています。これにより「吸収率上昇→キーホール安定化→さらに吸収率上昇」という連成を、発散しない滑らかな形で近似します。

### 4. 熱伝導モードの溶け込み

熱伝導モードでは、深さはスポット径程度で飽和すると仮定し、

\[
h_{\rm cond}
=C_c d
\left[
1-\exp\left\{
-k_c\max\left(
\frac{\mathcal{H}}{\mathcal{H}_m}-1,0
\right)
\right\}
\right]
\]

とします。溶融閾値直下ではゼロ、閾値を超えると増加し、十分な入熱では \(C_cd\)へ漸近します。

### 5. キーホールモードの溶け込み

キーホールの移動方向エネルギーバランスから、基本深さを

\[
h_{\rm key,raw}
=
C_k\frac{\eta_k P}{v d_{\rm eff}}
\]

と置いています。実装上は

\[
d_{\rm eff}
=\sqrt{d^2+d_0^2}
\]

として、小スポット側で深さが非現実的に発散することを抑えています。

さらに低速・高入熱側の無限増大を避けるため、表面張力と反跳圧の釣り合いを模した上限

\[
h_{\rm limit}
=
\frac{2C_r\eta_kP}{\pi\gamma}
\]

を設け、滑らかな最小値

\[
h_{\rm key}
=
\left(
h_{\rm key,raw}^{-n}
+h_{\rm limit}^{-n}
\right)^{-1/n}
\]

で接続します。

最終的な溶け込み深さは

\[
h
=g_m\left[(1-g_k)h_{\rm cond}+g_kh_{\rm key}\right]
\]

です。したがって、未溶融から熱伝導、遷移、キーホールまで連続的に変化します。

### 6. スパッタモデル

スパッタは単一機構ではなく、次の4つの不安定性を重ねます。

#### モード遷移不安定性

\[
\phi_{\rm tr}=4g_k(1-g_k)
\]

キーホール生成・消滅が交互に起こりやすい遷移域 \(g_k\approx0.5\)で最大になります。

#### 低速側のキーホール崩壊

毛管安定性指標

\[
\Pi_{\rm cap}
=
\frac{C_r d v}{2\gamma C_k}
\]

が小さい領域を不安定とし、

\[
\phi_{\rm collapse}
=g_k S(\Pi_{\rm cap}^{-1})
\]

で表します。低速では溶融池への熱滞留が大きく、キーホール壁の崩壊や気泡閉じ込めに伴う飛散が増える、という傾向を担います。

#### 高強度側の反跳圧噴出

\[
\phi_{\rm recoil}
=g_k S(\eta I_0;I_{\rm sp})
\]

吸収ピーク強度が高いほど蒸発反跳圧が強くなり、溶融金属の噴出が増える項です。

#### 高速側の前壁傾斜・ハンピング

\[
\Pi_{\rm tilt}
=
\frac{v}{C_k\eta_k I_0}
\]

を前壁傾斜の指標として、

\[
\phi_{\rm hump}
=g_k S(\Pi_{\rm tilt};\Pi_{\rm tilt,c})
\]

とします。高速走査時の溶融池後方への流れ、ビードのハンピング、不安定化を近似します。

総合スパッタ傾向は

\[
\Phi_{\rm sp}
=g_m(
1.5\phi_{\rm tr}
+1.0\phi_{\rm collapse}
+0.8\phi_{\rm recoil}
+0.8\phi_{\rm hump})
\]

です。これを基準値 \(\Phi_9\)で正規化して

\[
L_{\rm spatter}
=
\operatorname{round}
\left[
9\operatorname{clip}
\left(\frac{\Phi_{\rm sp}}{\Phi_9},0,1\right)
\right]
\]

とし、`0:なし`～`9:大量`の10段階へ量子化します。

このスパッタ値は現時点で「傾向レベル」であり、質量や個数ではありません。実験では、例えば捕集質量 `[mg/mm]`、画像中粒子数、付着面積率などを定義し、その連続値に対してモデルを校正した後、必要なら10段階へ区分してください。

## 適応探索アルゴリズム

各グリッド交点を、コストのかかる実験1回として扱います。

1. 現在の直方体範囲を各軸3点、計最大 \(3^3=27\)点で実験
2. 入力を全探索範囲の0–1へ正規化
3. 溶け込み深さとスパッタレベルに独立したGaussian Processを学習
4. 各予測点で2条件の同時成立確率を計算
5. 確率閾値以上の連結成分を抽出
6. 状況に応じて次の探索更新ルールを選択
   - 通常時は各成分を囲む軸平行直方体へ縮小
   - 候補が親範囲の境界へ接した場合は外向きにシフト・再拡大
   - GP標準偏差が許容値を超える場合は不確実領域を再拡大
   - 縮小率が停滞した場合は同時成立確率のピーク方向へ平行移動
   - 収束前および定期判定時は全領域へ確認用プローブを追加
   - 候補が消えた場合は保存した親範囲へバックトラック
7. 成分が分離していれば探索枝を分岐
8. 次の探索箱同士が重複・近接する場合は、以下の条件で反復統合
   - 小さい箱に対する重複率が30%以上、または包含率が80%以上
   - 統合直方体の体積膨張が元の和集合体積の1.5倍以下
   - 近接箱では間隔が次グリッド1セル以内
   - 完全包含以外では橋渡し点の同時成立確率が閾値以上
9. 各回復ルールの反復上限を守りながら、境界の予測不確かさと
   直方体寸法が十分小さくなるまで反復

GPには定数カーネル、Matérnカーネル、Whiteカーネルを用います。2つのGPを独立と仮定した同時成立確率は

\[
p_{\rm feasible}
=
P(h\ge h_{\min})
P(L<L_{\max})
\]

ではなく、積

\[
p_{\rm feasible}
\approx
P(h\ge h_{\min})
\times
P(L<L_{\max})
\]

で求めます。独立仮定が不適切な実データでは、多出力GPやコピュラ、制約付きベイズ最適化へ置き換える余地があります。

### 終了条件

- **converged**：有望領域を囲む箱が要求分解能以下で、GP標準偏差も許容値以下
- **no_feasible_region**：信頼区間を考慮した楽観判定でも成立可能領域がなく、確認ステップ後も同じ
- **max_steps_inconclusive**：最大ステップ数までに上記を確定できない

条件を満たす領域が複数あれば、それぞれ独立した直方体として返します。
各ステップで選択されたルールと理由は
`adaptive_search_summary.json`の`step_history`へ記録されます。
ボックス統合時は、統合元ID、重複率、体積膨張率、橋渡し確率も
`box_merge_events`へ記録されます。

## 主要な校正パラメータ

`src/physics_model.py`の`ModelParameters`に集約しています。

| 分類 | 代表パラメータ | 意味 |
|---|---|---|
| 材料 | 密度、熱拡散率、比熱、融点、融解潜熱 | 鉄鋼材料の熱物性 |
| 吸収 | 熱伝導・キーホール吸収率 | 表面状態・波長・多重反射 |
| 遷移 | 溶融・キーホール閾値と幅 | モード境界と遷移の鋭さ |
| 深さ | 熱伝導深さ比、掘削係数、小径補正 | 溶け込み深さの絶対値と飽和 |
| スパッタ | 強度閾値、崩壊幅、前壁傾斜閾値 | 各不安定機構の発現位置 |
| 序数化 | レベル9基準値 | 連続傾向を10段階へ写像 |

校正時は、まず溶融・キーホール境界、次に溶け込み深さ、最後にスパッタ指標の順で合わせるとパラメータ間の混同を抑えやすくなります。

## 適用限界と次の改善

- ガウシアン単一モードを仮定しており、実際のマルチモードファイバー出射のトップハット化、リング形状、M²、焦点外しを直接表現しない
- 板厚貫通、裏面ビード、ギャップ、継手形状、溶加材を扱わない
- 温度依存物性、流体計算、Marangoni対流、蒸気プルーム、シールドガス流を陽には解かない
- スパッタの序数レベルは未校正の現象論モデル
- 観測ノイズは実験装置・断面測定・画像検査に合わせて再設定が必要

実データを得た後は、物理モデルの出力をGPの平均関数として使う、残差のみをGPで学習する、または係数をベイズ推定する「physics-informed surrogate」へ発展させるのが適しています。
